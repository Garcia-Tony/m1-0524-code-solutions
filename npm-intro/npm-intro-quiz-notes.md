# npm-intro-quiz-notes

## Quiz Questions

Answer the following questions in the provided markdown file before turning in this exercise:

- What is NPM?
  It is a package manager for the JavaScript programming language and is primarily used for managing packages (libraries or modules) in Node.js projects.

- What is a package?
  A bundle of code and metadata that can be used to add functionality to a project.

- What are some other popular package managers?
  Yarn, Maven, and Gradle.

- How can you create a `package.json` with `npm`?
  Using the npm command.

- What is a dependency and how do you add one to a package?
  A dependency is a package the npm relies on and you can add one by npm install.

- What happens when you add a dependency to a package with `npm`?
  It updates the package.json.

- What is a devDependency and how do you add one to a package?
  A devDependency is a type of package dependency that is required only during the development and testing phases of a project, rather than in the production environment. To add one you use npm install --save-dev command.

- How do you define and run npm scripts? Why are these useful?
  npm scripts are custom commands defined in the scripts section of your package.json file. In order to run it, it must be added. These ensure that scripts are run in a consistent manner across different environments and development setups.
