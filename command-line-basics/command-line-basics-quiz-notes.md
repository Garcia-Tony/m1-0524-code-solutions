# command-line-basics-quiz-notes

## Quiz Questions

Answer the following questions in the provided markdown file before turning in this exercise:

- What is a CLI?
  Command-Line Interfaces. Means of interacting with a computer program by inputting lines of text called command-lines.

- What is a GUI?
  Graphic User Interface. A form of user interface that allows users to interact with electronic devices through graphical icons and visual indicators such as secondary notation.

- Give at least one use case for each of the commands listed in this exercise.

  - `man`
    man is the system's manual pager. Each page argument given to man is normally the name of a program, utility or function.

  - `cat`
    cat concatenates files to stand output.

  - `ls`
    ls lists information about the files

  - `pwd`
    pwd prints the full filename of the current working directory.

  - `echo`
    echo displays a line of text.

  - `touch`
    touch updates the access and modification times of each File to the current time. changes file timestamps.

  - `mkdir`
    mkdir creates the directories, if they do not already exist.

  - `mv`
    mv renames files, or moves files to directories.

  - `rm`
    rm removes each specified file.

  - `cp`
    cp copies files and directories.

- What are the three virtues of a great programmer?
  Laziness, Impatience, and Hubris.
